# roboarc (reserved)

This directory is reserved for the Python package `roboarc`: Gymnasium-style environments over the same physics and
tooling the graded tasks run (`source/topogym/` with `rcb_topogym.py` for the puzzles, `rcb_ikea.py` for IKEA). It is
built on the branch `api`. The tasks themselves are evaluated with Harbor (see the repository README).
