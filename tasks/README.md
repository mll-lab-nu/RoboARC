# RoboARC tasks

Harbor tasks in which a coding agent controls a simulated robot and must deliver one replayable trajectory for a frozen
scene instance, in privileged or standard mode: `roboarc-<family>-<NN>-i01-<mode>`. They are generated by
`scripts/roboarc/mk_tasks.py` (never edit them by hand; `--check` compares them with a fresh render). See the repository
README for running them, `docs/benchmarks/roboarc.md` for the benchmark's rules and `docs/PROTOCOL.md` for the contract
and scoring.
